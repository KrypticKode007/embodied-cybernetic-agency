# Embodied Cybernetic Agent and Structural Failure

A falsifiable research framework for **embodied, self-modeling, failure-aware artificial agents**.

This project implements and evaluates a family of agents that differ in their coupling between:

1. **World model** (environmental prediction)
2. **Interoceptive model** (substrate / resource telemetry)
3. **Action controller** (environment-changing actions)
4. **Metacognitive self-model** (reliability and failure-source estimation)
5. **Regulation and recovery** (risk-sensitive mode switching and shutdown)

The goal is to measure **cybernetic autonomy, safety, calibration, resilience, and recoverability** under controlled disturbances.
